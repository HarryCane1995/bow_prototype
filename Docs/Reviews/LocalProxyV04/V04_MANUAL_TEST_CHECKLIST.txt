V04 MANUAL TEST CHECKLIST — ПРОВОДИТ ПОЛЬЗОВАТЕЛЬ

API QA выполнено отдельно. Эти человеческие проверки ещё НЕ пройдены.
Используйте копию .blend или Undo между тестами. Базовый Seed 17.
В каждом тесте следите именно за обновлением ВО ВРЕМЯ Edit Mode.
Не нажимайте Apply / Bake и не запускайте rebuild-скрипты.

TEST 1 — HORIZONTAL EXTRUDE
Выберите LEVEL_PROXY → Tab → Face Select → внешняя торцевая грань → E.
Вытяните секцию на 15–25 m горизонтально.
EXPECTED: внутри нового объёма появляются новые surfaces; старый участок
не растягивается. Результат виден до выхода из Edit Mode.

TEST 2 — TURN
Продолжите конец через E, сместите новую cap в сторону через G, при желании R Z.
EXPECTED: новый участок и его walls/landing surfaces следуют повороту.
Не создавайте самопересечение или перекрученные cap.

TEST 3 — VERTICAL EXTRUDE
Выберите верхнюю грань конечной секции → E Z → поднимите на 20–30 m.
EXPECTED: внутри добавленного объёма появляются плавающие площадки,
wall-jump/wallrun поверхности и при Grapple Bias > 0 candidate markers.

TEST 4 — LONG VERTICAL SECTION
Ещё раз вытяните верхнюю cap вверх на 20–30 m.
EXPECTED: добавятся новые уровни; старые площадки ниже junction не
перераспределятся по новой общей высоте. Supports не обязательны и не строятся.

TEST 5 — SEED
Измените Seed: 17 → 42 → 73 → 17 в N → V04 Local либо
Object Properties → Custom Properties у LEVEL_PROXY.
EXPECTED: наполнение меняется; исходная форма proxy не меняется;
возврат 17 воспроизводит прежнее наполнение при неизменной topology.

TEST 6 — VERTICALITY / PLATFORM DENSITY
На высоком участке сравните Verticality 0.2 / 1 и Platform Density 0 / 1.
EXPECTED: меняются наличие и слои площадок. Шаг по высоте примерно 4.8–3.1 m;
этот параметр намеренно перестраивает вертикальное наполнение.

TEST 7 — GRAPPLE BIAS
Сравните Grapple Bias 0 / 1; объект GRAPPLE_CANDIDATES должен быть видимым.
EXPECTED: при 0 markers отсутствуют, при 1 появляются жёлтые markers
над gaps/площадками; ни один не должен висеть за пределами proxy.

TEST 8 — STEEP RAMP
Ramp Presence = 1, Density = 1; сравните Ramp Steepness 45 / 55 / 70.
EXPECTED: в достаточно высоких участках меняется реальный уклон рамп.
Проходимость 70° в движке пока НЕ проверялась.

TEST 9 — DELETE / MODIFY PROXY
Передвиньте несколько vertices; попробуйте inset или bevel локальной секции.
Затем удалите целый отдельный island или ветку с восстановлением cap.
EXPECTED: меняется соответствующее наполнение. Delete только одной грани
оставляет дыру: весь output будет пуст до восстановления замкнутости.
Это защитное поведение, а не зависание; Undo должен сразу вернуть результат.

TEST 10 — DISCONNECTED ISLAND
В Edit Mode наведитесь на отдельный closed island → L → Shift+D → G.
Либо добавьте отдельный cube в Edit Mode и увеличьте примерно до 12×20×12 m.
EXPECTED: второй island получает своё наполнение; первый не меняется.
Не накладывайте islands друг на друга без корректного объединения объёмов.

TEST 11 — CUTTER
Use Cutter = true на LEVEL_PROXY. Покажите LEVEL_CUTTER в Outliner.
Переместите его к текущему proxy (сейчас тот находится около X=140 m),
затем Tab и измените Cutter.
EXPECTED: локальный кусок OUTPUT и helpers вычитается сразу;
сам LEVEL_PROXY остаётся прежним. По окончании выключите Use Cutter.

TEST 12 — VERTICAL EXTENSION STABILITY
Запомните размеры стен и площадок первой горизонтальной секции.
Вытяните конец вперёд, затем его верхнюю грань вверх на 25 m.
EXPECTED: первая секция остаётся прежней по размерам и положению;
добавление происходит в новом объёме и ближайшем junction.

TEST 13 — CONTAINMENT
Осмотрите wire proxy вокруг generated surfaces и markers с разных сторон,
особенно поворот, узкую шахту и верхние платформы. Сравните Preview 0 / 1.
EXPECTED: ничего видимо не выступает из авторского объёма.
Разрешённого внешнего overhang нет; числовая погрешность проверки 0.3 mm.

TEST 14 — WIDE AFTER NARROW
Из узкой секции сделайте E, затем расширьте новую cap через S по ширине.
При необходимости сделайте ещё один E для постоянной ширины arena.
EXPECTED: расширяется наполнение только нового кармана;
старый узкий участок сохраняет ширину.

ЧТО ПРИСЛАТЬ ПО РЕЗУЛЬТАТАМ
Номер теста; OK / проблема; Seed и изменённые параметры; что сделали;
обновился ли output именно внутри Edit Mode; воспроизводится ли после Undo.
Для проблемы формы полезны .blend или два вида до/после.

ИЗВЕСТНЫЕ ГРАНИЦЫ
Quad extrusion — основной случай. Сложные n-gons, треугольники, очень узкие
или сильно перекошенные sections могут заполняться неравномерно.
Subdivide / dissolve изменяют локальные patches и могут изменить их Seed ID.
Самопересечения, внутренние caps, перевёрнутые normals — невалидный volume.
При обычном E автоматически чинить caps не требуется.
Неединичный Object Scale меняет физические размеры gameplay surfaces.
Система соблюдает локальные movement budgets, но не доказывает связность
или проходимость всего маршрута; human gameplay testing остаётся на потом.
